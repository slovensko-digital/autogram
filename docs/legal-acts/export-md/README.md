# Markdown export of the legal-act register

The same rows as the [Excel export](../export/README.md), as plain Markdown tables, one file per register document. Generated by [`scripts/export-legal-register-xlsx.py`](../../scripts/export-legal-register-xlsx.py).

**Columns.** Provision · Row type · Parent · Official provision text · Text source · Requirement / assessment · Relevance · Assessment · Ignored? · Reason / evidence needed · Dates / notes · Official URL · Register document, plus the empty columns Owner, Review state, Priority, Evidence URL, Notes, Last reviewed.

**Text source.** The official text URL and what was matched: the row's own unit, a parent unit, the whole article or annex, or nothing - the row then still needs a source review.
