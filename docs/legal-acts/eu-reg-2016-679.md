# Regulation (EU) 2016/679 — General Data Protection Regulation (GDPR)

## Executive summary

**Assessment: 8 October 2026; repository baseline: `5ca91d5c`.** GDPR concerns processing of personal data, not a certification of signing software. Local documents, certificate identities and potentially identifying filenames can fall within its definitions. A professional user determining processing purposes may be a controller; a purely personal/household user may be exempt. Neither installing Autogram nor publishing its source automatically makes the publisher the controller or processor of every user's documents.

The confirmed scope is the desktop application, local API and CLI. The publisher operates no Autogram document-receiving service and is not a qualified trust-service provider. **Support, billing, employment and any diagnostic-data receipt require separate role and data-flow decisions.** Their contracts, notices, records and procedures were not supplied. Absence of those documents is not proof of a violation. Network requests also mean “local software” must not be read as “no external communication”.

Inspected code establishes local file ingestion, configurable HTTP/HTTPS API construction, debug logging of filenames, an update request to GitHub, and XML external-resource restrictions with regression-test assertions. These are narrowly evidenced behaviours, not proof of Articles 5, 25 or 32 compliance. Overall organisational measures and deployment risks remain **Unknown**. No row assigns **Not done** merely because organisational evidence is missing, and no recital or definition is treated as a completed software task.

**Version limitation:** the complete official **original English OJ text published 4 May 2016** was obtained. Direct access to the consolidated EUR-Lex text was blocked; the later corrigenda and a current consolidation were not obtained. Coverage below is complete for that original text, **not an assertion of complete current corrected-text coverage**.

### Inspected repository evidence

- **E1 — Local file processing:** [`BatchGuiFileResponder.onBatchStartSuccess`](../../src/main/java/digital/slovensko/autogram/ui/BatchGuiFileResponder.java), lines 50–66, creates `FileDocument`/`SigningInput` and submits local jobs. This does not establish any support-service receipt or legal basis.
- **E2 — Logs:** the same file, lines 54–60 and 75–79, passes filenames/errors to [`Logging.log`](../../src/main/java/digital/slovensko/autogram/util/Logging.java), lines 14–22, which uses `logger.debug`. [`simplelogger.properties`](../../src/main/resources/simplelogger.properties), lines 1–3, defaults to INFO. Potentially identifying filenames can enter debug output if enabled; retention, user configuration, redaction and support sharing need verification. It is not established that default releases transmit these logs.
- **E3 — Local API/security choice:** [`AutogramServer.start/buildServer`](../../src/main/java/digital/slovensko/autogram/server/AutogramServer.java), lines 35–71 and 74–105, exposes signing/certificate/batch endpoints and binds the supplied hostname, with HTTP or HTTPS selected by a parameter. HTTPS construction uses a local PKCS12 file and TLS configuration. This read does not prove all launch defaults, origin authorisation, client authentication, safe network exposure or release security.
- **E4 — Update network request:** [`Updater.newVersionAvailable`](../../src/main/java/digital/slovensko/autogram/core/Updater.java), lines 19–40, makes a GET request to GitHub releases, skipping development versions. Transport metadata can identify a user; provider roles, notices, invocation settings and transfer analysis were not established. No document upload appears in this method, which is not a whole-application traffic audit.
- **E5 — XML hardening:** [`XMLUtils.getSecureDocumentBuilder/getSecureTransformerFactory/getSecureSchemaFactory`](../../src/main/java/digital/slovensko/autogram/util/XMLUtils.java), lines 18–55, prohibits external DTD/schema/stylesheet access and disables several transformation features. [`XMLUtilsTest`](../../src/test/java/digital/slovensko/autogram/util/XMLUtilsTest.java), lines 80–123, contains external entity/stylesheet/DTD rejection assertions. Tests were inspected, **not executed**. This is evidence of particular controls, not overall security or ongoing testing effectiveness.
