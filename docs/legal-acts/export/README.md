# Spreadsheet export of the legal-act register

One workbook per register document, generated by [`scripts/export-legal-register-xlsx.py`](../../scripts/export-legal-register-xlsx.py).
Each file holds the provisions of that act, the register's assessment and the verbatim text of each provision taken from the official publication.

**Columns.** Provision, Row type, Parent, Official provision text, Text source, Requirement / assessment, Relevance, Assessment, Ignored?, Reason / evidence needed, Dates / notes, Official URL, Register document, plus the empty columns Owner, Review state, Priority, Evidence URL, Notes and Last reviewed.

**Text source.** The official text URL and what was matched: the row's own unit, a parent unit, the whole article or annex, or nothing - the row then still needs a source review.

**Working copy.** The spreadsheets are generated from the Markdown register; edits here are not written back. Close an item in the register document and re-export.
