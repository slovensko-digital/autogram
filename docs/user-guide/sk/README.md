# Používateľská príručka Autogramu

Autogram je aplikácia pre Windows, macOS a Linux na podpisovanie a overovanie dokumentov podľa nariadenia eIDAS. Dokumenty môžete podpisovať priamo v aplikácii, z príkazového riadka alebo z webových stránok, ktoré Autogram volajú cez HTTP API.
